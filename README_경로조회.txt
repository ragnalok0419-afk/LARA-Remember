LARA 도로거리·차량정보 기능

1. 기존 검은 서버창 종료.
2. ZIP 전체 압축 풀기 → 여기를_더블클릭해서_LARA_실행.bat 실행.
3. 오른쪽 차량 상태에서 출발 도시를 서울, 주행가능거리를 160으로 입력하고 차량 정보 적용.
4. 대화: 지금 차량 상태 알려줘 → 서울에서 부산까지 몇 킬로야? → 그럼 지금 연료로 갈 수 있어?
5. 도시 중심 간 온라인 OSRM 도로 경로를 조회합니다. 실시간 교통이나 개인별 실제 출발 위치와 다릅니다.
6. 외부 OSRM 데모는 교육용 소규모 테스트 전용입니다. 시간당 과도한 요청 금지, 1초당 최대 1회. 상용 서비스는 운영 계약된 국내 경로 API 필요.
7. 도시 이름이 아닌 정확한 주소·건물명 검색은 아직 미구현입니다. 모르는 거리는 지어내지 않습니다.
8. 경로 조회는 네트워크에 연결될 때만 작동합니다.
9. 지원: 서울 부산 인천 수원 대전 대구 광주 울산 세종 춘천 강릉 전주 청주 천안 포항 창원 성남 용인 제주 안양 안산 김해 김포 평택
10. 주행가능거리 160km는 시뮬레이션이며 실제 차량 연료량 조회가 아닙니다.
