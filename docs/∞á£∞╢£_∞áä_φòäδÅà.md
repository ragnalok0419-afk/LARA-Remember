# 2026-11-14 현재 상태와 제출 체크

## 즉시 사용할 수 있는 것
- `app/src/main/assets/index.html`: 작동하는 독립 HTML 기반 데모 소스. 기기·브라우저에 따라 음성 기능이 제한될 수 있음.
- `server.py`: Ollama 모델이 PC에 설치돼 있을 때 사용할 선택형 대화 서버.
- `docs/01_기획서_복붙용.txt`: 신청서 1~7번 문구.
- `README.md`: 빌드·실행·제약 설명.

## 실재하지만 검증되지 않은 것
- `app/` Android Studio 프로젝트 소스: 컴파일 검증 전.
- Android STT/TTS 브리지: 실제 기기 검증 전.

## 아직 없는 것
- 실제 설치를 확인한 release APK.
- Pleos Connect SDK 공식 연동, 에뮬레이터 검증.
- 모든 대화를 완벽히 이해·기억하는 자체 내장 LLM.
- 공개 GitHub URL 및 커밋 해시.
- 실제 차량 센서, 내비게이션 조작.

## 안전한 1차 제출 전략
1. 기획서 본문에는 구현/미구현 사실을 구분하여 작성.
2. 브라우저 인터랙티브 목업 영상·화면과 소스 프로젝트를 제출 가능. 이 자료는 '모형 시연'이라고 표시.
3. 기존에 만든 것으로 설명된 Qwen3-1.7B 기반 별도 APK가 실제 존재한다면 원본을 확보하고 설치·서명·동작을 검증한 뒤 업로드. 원본 없이 그 APK가 포함됐다고 기재하지 말 것.
4. GitHub 가산점을 받으려면 실제 검증된 release APK를 `apk/`에 업로드해야 함.
5. 신청서 7번의 'GitHub 미업로드', 'APK 미검증' 문구는 실제 업로드/검증이 완료되었을 때에만 링크와 사실로 바꿀 것.
6. 신청서 서명은 본인이 수행해야 함.
